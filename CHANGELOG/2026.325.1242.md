# 2026.325.1242 — feat(cstream): own the venue probes and the input methods, and gate the candies

## Summary

The `cstream:` verb's venue half moves into the plugin that executes it, so one verb has one owner (R2; opencharly/opencharly#1201 G1 and G2).

- **`cstream-probes`** — the consumer-side probes move here from `pod-cstream`'s `etc/`:
  - `cstream-login-probe` drives one PAM attempt through the session leader, password over stdin;
  - `cstream-frame-probe` pulls a frame back **through** the negotiated WebRTC track, so a broken encoder, negotiation or transport fails it;
  - `stream-probe` maps a window on the streamer's own compositor and asserts the frame tap changes. It mutates the desktop, so it is bed-only, which is why it lives here and not in the server image.
- **`cstream-probe-account`** — the bed-only login fixture moves here from `opencharly/distro-cachyos`. It sets a password on the container's own runtime account at build time. It must never be composed into a shipped image, and its description says so.
- **The input methods** — `type`, `key`, `move`, `click` and `scroll` run `cstream-input` (shipped with the streamer) over the real WebRTC data channel. `schema/cstream.cue` is the single source and `params/` is regenerated from it; the scroll deltas are documented in GStreamer's sink convention (120 per notch, positive up/left), which the gst-wayland-display element maps onto the seat's wheel axis.
- **`candy/plugin-cstream/go.mod` + `go.sum`** move `sdk` `v0.2026320.1345` → `v0.2026324.8` and `spec` `v0.2026320.1252` → `v0.2026324.636` (and the indirects those drag: `containerd/*`, `sirupsen/logrus`, `golang.org/x/term`). This is required, not drift: `params/cue_types_gen.go` is regenerated from `schema/cstream.cue` by the newer `spec`'s CUE pipeline, and the new provider/method wiring is compiled against the newer `sdk`. The drift tests (`params_repro_test`, `schema_contract_test`, `decode_test`) run against exactly this pair.
- **A root `charly.yml`** with `discover: - path: candy` makes this repo a project. Without it the repo was project-less and the stock candy gate asserted nothing (opencharly/charly#459; opencharly/plugin-gpu fixed it the same way). `AGENTS.md`'s "no root `charly.yml`" prose is corrected in the same change.

Consumer: `opencharly/pod-kde-cstream`'s `kde-cstream-check` box composes `cstream-probes` and `cstream-probe-account`.
